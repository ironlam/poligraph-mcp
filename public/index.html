Connexion

Opérationnel en deux minutes.

Choisissez votre client, copiez la configuration et commencez à interroger les données publiques de Poligraph.

i

L’alias poligraph-mcp.vercel.app/mcp reste disponible pour les configurations existantes.

claude_desktop_config.json 
{
  "mcpServers": {
    "poligraph": {
      "type": "streamable-http",
      "url": "https://mcp.poligraph.fr/mcp"
    }
  }
}
Terminal 
claude mcp add poligraph --transport http https://mcp.poligraph.fr/mcp
Streamable HTTP 
https://mcp.poligraph.fr/mcp

Aucune authentification n’est requise. Les clients serveur à serveur peuvent se connecter sans en-tête Origin.

Confiance

Un accès ouvert,
des limites claires.

Le serveur donne accès aux mêmes informations publiques que Poligraph, sans accès direct à la base de données et sans fonction d’écriture.
