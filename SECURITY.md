# Politique de sécurité

## Périmètre

Cette politique couvre le serveur MCP PoliGraph et son intégration avec l’API publique
PoliGraph.

## Signaler une vulnérabilité

Signalez toute vulnérabilité de manière privée à [contact@poligraph.fr](mailto:contact@poligraph.fr).
N’ouvrez pas d’issue GitHub publique pour une vulnérabilité qui n’a pas encore été divulguée.

Merci d’indiquer dans le signalement :

- la version concernée ;
- l’environnement utilisé ;
- l’impact observé ou potentiel ;
- les étapes minimales permettant de reproduire le problème ;
- les éléments de preuve strictement nécessaires à sa compréhension.

Un accusé de réception et un suivi seront fournis. Cette indication ne constitue pas un
engagement sur un délai contractuel de traitement ou de correction.

Les erreurs éditoriales et les problèmes de données non sensibles peuvent continuer à être
signalés dans les issues GitHub publiques.
